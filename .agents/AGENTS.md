# Project AGENTS.md Rules

## Design System & Color Palette Guidelines

Always strictly enforce the following Color System and Typography across ALL frontend pages, components, and modals:

- **Primary Brand Color**: `#2563EB` (Royal Blue) - Used for primary buttons, active CTA actions, main badges, active navigation indicators.
- **Secondary Accent Color**: `#EFF6FF` (Ice Blue Tint) - Used for light card backgrounds, search inputs, subtle container highlights, active tab fills.
- **Tertiary Accent Color**: `#3B82F6` (Electric Blue) - Used for secondary brand highlights, hover states, progress bars.
- **Neutral Dark Color**: `#1F2937` (Dark Charcoal / Slate 800) - Used for primary body text, headlines, dark containers, high contrast elements.
- **Typography**: Inter Font (`font-sans`).
